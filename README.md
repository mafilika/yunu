# Tumza Bonny website (Netlify)
1. Put this folder in a GitHub repository and import it in Netlify (Add new site > Import an existing project).
2. Netlify > Site configuration > Environment variables: add ADMIN_PASSWORD (at least 10 characters). Redeploy.
3. Open https://YOUR-SITE/admin/ and log in. Set your real domain under Search (SEO).
